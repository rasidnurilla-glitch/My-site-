Бақылау сұрақтары

1. CSS дегеніміз не?

CSS — HTML элементтерінің сыртқы көрінісін безендіруге арналған стильдер тілі.

2. CSS селекторы дегеніміз не?

CSS селекторы — стиль қолданылатын HTML элементін анықтайтын белгі.

3. Элемент селекторы қалай жазылады?

Элемент селекторы HTML тегінің аты арқылы жазылады. Мысалы: p { color: blue; }

4. Class селекторы қалай белгіленеді?

Class селекторы нүкте . белгісімен жазылады. Мысалы: .important { color: red; }

5. ID селекторы қалай белгіленеді?

ID селекторы # белгісімен жазылады. Мысалы: #title { color: blue; }

6. Class пен ID арасындағы негізгі айырмашылық қандай?

Class бірнеше элементке қолданылуы мүмкін, ал ID бірегей элементті анықтау үшін қолданылады.

7. Әмбебап селектор қандай қызмет атқарады?

Әмбебап селектор * барлық HTML элементтерін таңдау үшін қолданылады.

8. Топтық селектор қалай жазылады?

Топтық селектор бірнеше селекторды үтір арқылы жазу арқылы құрылады. Мысалы: h1, h2, p { color: blue; }

9. :hover псевдокласы не үшін қолданылады?

:hover псевдокласы курсор элементтің үстіне келген кезде оның стилін өзгерту үшін қолданылады.

10. CSS қасиеті мен мәнінің айырмашылығы қандай?

Қасиет — қандай сипаттаманы өзгертетініміз, ал мән — сол сипаттаманың қандай болатыны. Мысалы: color: red;. Мұнда color — қасиет, red — мән.

11. CSS каскад принципі дегеніміз не?

CSS каскад принципі — бір элементке бірнеше стиль берілген кезде олардың басымдығына қарай қолданылатын стильді анықтау принципі.

12. Specificity дегеніміз не?

Specificity — CSS селекторларының басымдық деңгейі. ID селекторы class селекторынан, ал class селекторы элемент селекторынан басым болады.

13. Inline CSS дегеніміз не?

Inline CSS — CSS стилін HTML элементінің style атрибутының ішінде жазу. Мысалы: <p style="color: red;">Мәтін</p>

14. Ішкі CSS қалай жазылады?

Ішкі CSS HTML құжатының <head> бөліміндегі <style> тегі ішінде жазылады.

15. Сыртқы CSS файлы HTML құжатына қалай қосылады?

Сыртқы CSS файлы HTML құжатына <link> тегі арқылы қосылады. Мысалы: <link rel="stylesheet" href="style.css">
